# FOOD LOVERS — DSM Studio UI to Code #02

A fictional modern brunch restaurant concept inspired by the user-supplied one-page PDF. Recreated with semantic HTML, CSS and vanilla JavaScript; no build tools or frameworks.

## Run
Open `index.html` in a browser, or serve the folder using VS Code Live Server.

## Features
- Responsive desktop/tablet/mobile layouts
- Food gallery with lightbox
- Menu category filters and details modal
- Scroll reveals with reduced-motion support
- Mobile navigation
- Newsletter demo (no data is transmitted or stored)

## Photos
Photos load from Unsplash CDN and require an internet connection. Review photo licenses and image suitability before commercial publication. The brand, menu, prices, and restaurant are fictional. The email button is a placeholder.

## Publish to GitHub Pages
Upload `index.html`, `css/`, and `js/` to the repository root. In Settings → Pages select Deploy from a branch, `main`, `/ (root)`.
